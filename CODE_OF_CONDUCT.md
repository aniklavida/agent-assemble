# Code of Conduct

## Our Standard

Be respectful, specific, and constructive. Harassment, discrimination, threats, doxxing, and deliberately disruptive behavior are not accepted in any repository space.

Expected behavior includes:
- Providing concrete, technical feedback focused on code and documentation rather than individuals.
- Communicating with empathy toward contributors with differing levels of experience.
- Focusing on collaborative problem-solving and adhering to project verification standards.

## Scope

This Code of Conduct applies within all repository spaces, including pull requests, issue threads, commit discussions, and public communication channels associated with the project.

## Enforcement and Reporting

Project maintainers are responsible for clarifying and enforcing our standards of acceptable behavior. Maintainers may remove abusive content, close disruptive threads, or restrict participation when necessary.
