# The Founding Incident

This role is not a generic research checklist. It answers one recorded failure in
this project's own history:

> A product premise was built on an unverified claim about an upstream project
> and survived until someone finally opened the repository.

The claim was never a gate item. Nothing failed, because nobody had asked whether
anyone had actually checked it. An advisory principle reminds an agent that is
already working; a prescriptive gate compares against a known answer. Neither
reaches a premise everyone has already accepted as true.

`docs/SPEC.md` records the incident under *The founding incident*.

## What the role does with it

- For each claim the work rests on, ask whether someone opened the source, ran
  the thing, or read the documentation at the version actually used.
- Record the evidence found, or record that the claim is unchecked.
- Produce no verdict. The reviewer decides what an unchecked claim means.
