# Image Tag Resolution

A tag is not a licence. Each tag below is resolved to the product **and
version** behind it, which is what fixes the licence. `redis:7-alpine` reads as
"Alpine, which is permissive" — the Alpine base is not the problem; the Redis
version on top of it is.

| Image tag | Product | Resolved version | Licence |
|---|---|---|---|
| redis:7-alpine | Redis | 7.4.0 | RSALv2 |
| postgres:16-alpine | PostgreSQL | 16.3 | PostgreSQL |
